# app-ads.txt — Gikeon
# Authorized Digital Sellers for Apps (IAB Tech Lab). Covers every Gikeon app whose
# Play listing points its Developer Website at https://gikeonsupport-hub.github.io/
#
# WHY THIS FILE MATTERS
# A DSP deciding whether to bid on an impression from one of our apps reads the developer
# website from the Play listing, fetches /app-ads.txt from its root, and only accepts bid
# requests from sellers named here. Without a matching line, most demand — including
# Google's own DV360 — will not bid at all.
#
# RULES THAT ARE EASY TO GET WRONG
#   * It must live at the ROOT of the domain: https://gikeonsupport-hub.github.io/app-ads.txt
#     A project-page path such as /repo-name/app-ads.txt is NOT crawled.
#   * It must be served as text/plain over HTTPS. GitHub Pages does this for a .txt file.
#   * The Play Console listing must name this exact site under
#     Store settings -> Store listing contact details -> Website.
#   * Changes take up to 24h. AdMob -> Apps -> app-ads.txt has a "Check for updates" button
#     and shows the verification status per app.
#
